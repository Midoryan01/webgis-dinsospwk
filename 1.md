==================================================
1. LOGIC KATEGORI GRADUASI
==================================================

Kategori Graduasi mengikuti aturan berikut:

Kolom:
D = AUD
E = SD
F = SMP
G = SMA
H = DISABILITAS
I = LANSIA

Logic yang digunakan:

IF(
    OR(AUD > 0, SD > 0),
    "Rendah",
    IF(
        OR(SMP > 0, DISABILITAS > 0),
        "Sedang",
        IF(
            OR(SMA > 0, LANSIA > 0),
            "Tinggi",
            ""
        )
    )
)

Dalam bentuk Excel:

=IF(OR(D29>0;E29>0);"Rendah";IF(OR(F29>0;H29>0);"Sedang";IF(OR(G29>0;I29>0);"Tinggi";"")))

Prioritas kategori WAJIB mengikuti urutan tersebut:

1. Rendah
   - AUD > 0 ATAU SD > 0

2. Sedang
   - SMP > 0 ATAU DISABILITAS > 0

3. Tinggi
   - SMA > 0 ATAU LANSIA > 0

4. Kosong
   - Semua nilai = 0

Contoh penting:

AUD = 1
SD = 0
SMP = 0
SMA = 0
DISABILITAS = 0
LANSIA = 1

Hasil:
Kategori Graduasi = "Rendah"

Walaupun LANSIA memiliki nilai 1, hasil tetap "Rendah" karena kondisi Rendah memiliki prioritas lebih tinggi.

Contoh lain:

AUD = 0
SD = 0
SMP = 1
SMA = 0
DISABILITAS = 0
LANSIA = 1

Hasil:
Kategori Graduasi = "Sedang"

Dan:

AUD = 0
SD = 0
SMP = 0
SMA = 1
DISABILITAS = 0
LANSIA = 1

Hasil:
Kategori Graduasi = "Tinggi"

2. PERBAIKI IMPORT EXCEL
==================================================

Ini bagian yang sangat penting.

File Excel yang di-upload sebenarnya SUDAH memiliki data Kategori Graduasi yang benar.

Jangan mengganti Kategori Graduasi dari Excel dengan hasil kalkulasi baru secara otomatis.

Masalah saat ini:
- Data di Excel sudah benar.
- Setelah Excel di-import ke sistem, sebagian data memiliki Kategori Graduasi yang menjadi salah.
- Berarti kemungkinan terdapat kesalahan pada proses mapping kolom, parsing nilai, normalisasi data, atau assignment Kategori Graduasi ketika proses import.

Cari sumber masalahnya.

Periksa dengan teliti:

- Header Excel.
- Mapping nama kolom.
- Posisi/index kolom.
- Parsing angka AUD, SD, SMP, SMA, DISABILITAS, LANSIA.
- Mapping Kategori Graduasi.
- Apakah ada offset kolom.
- Apakah ada kolom kosong.
- Apakah ada perbedaan nama header seperti:
  "AUD"
  "SD"
  "SMP"
  "SMA"
  "DISABILITAS"
  "LANSIA"
  "Kategori GRADUASI"
- Perbedaan huruf besar/kecil.
- Spasi di awal/akhir header.
- Nilai kosong/null.
- Nilai angka yang terbaca sebagai string.
- Nilai "0", "1", atau angka lainnya yang mungkin salah diproses.
- Apakah Kategori Graduasi tertimpa setelah proses import.
- Apakah index kolom bergeser ketika membaca Excel.

Jangan berasumsi bahwa posisi kolom selalu aman.

Gunakan mapping berdasarkan NAMA HEADER jika memungkinkan, bukan hanya berdasarkan nomor index kolom.

Contoh konsep:

AUD -> data["AUD"]
SD -> data["SD"]
SMP -> data["SMP"]
SMA -> data["SMA"]
DISABILITAS -> data["DISABILITAS"]
LANSIA -> data["LANSIA"]
Kategori Graduasi -> data["Kategori GRADUASI"]

Pastikan proses import tidak secara tidak sengaja melakukan:

kategoriGraduasi = hasilPerhitunganYangSalah

ketika sebenarnya Excel sudah menyediakan:

kategoriGraduasi = row["Kategori GRADUASI"]

Jika memang ada normalisasi nilai kategori, lakukan secara aman.

Contoh nilai yang seharusnya dikenali:

"Rendah"
"Sedang"
"Tinggi"

Trim whitespace:

" Rendah " -> "Rendah"

Tetapi jangan mengubah kategori yang sudah valid tanpa alasan.

5. TABEL DATA PENGGUNA
==================================================

Pada tabel data pengguna, terdapat kolom:

AUD
SD
SMP
SMA
DISABILITAS
LANSIA

Angka pada masing-masing kolom harus diberikan warna sesuai kategori graduasi data tersebut.

Contoh:

Jika Kategori Graduasi = Rendah:
- angka AUD
- angka SD
yang berkaitan dengan kategori Rendah diberikan warna yang sesuai.

Jika Kategori Graduasi = Sedang:
- angka SMP
- angka DISABILITAS
diberikan warna sesuai kategori Sedang.

Jika Kategori Graduasi = Tinggi:
- angka SMA
- angka LANSIA
diberikan warna sesuai kategori Tinggi.

Namun jangan menghilangkan angka atau mengubah nilai datanya.

Yang diubah hanya visual/styling angka.

Contoh konsep:

Rendah:
AUD / SD -> warna indikator Rendah

Sedang:
SMP / DISABILITAS -> warna indikator Sedang

Tinggi:
SMA / LANSIA -> warna indikator Tinggi

Jika nilai = 0, tetap tampilkan 0 sesuai desain tabel, tetapi tidak perlu memberikan emphasis berlebihan.

Gunakan styling yang konsisten dengan UI project saat ini.

Jangan hardcode style inline jika project sudah menggunakan class/CSS/Tailwind/component styling.
